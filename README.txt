ARDITS GEBURTSTAGS-WEBSITE
==========================

DATEIEN
- index.html: Geburtstagsseite mit Überraschungsbutton
- erinnerungs-fotos.html: Galerie mit den vier hochgeladenen Fotos
- style.css: Design und responsives Layout
- bilder/: Enthält die vier Fotos foto1.png bis foto4.png

SO STARTET IHR DIE WEBSITE
1. ZIP-Datei entpacken.
2. Den Ordner in Visual Studio Code öffnen.
3. index.html im Browser öffnen. Optional: In VS Code die Erweiterung „Live Server“ installieren und auf „Go Live“ klicken.
